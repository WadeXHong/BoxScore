# Simulator Test Checklist

本輪修改都已通過編譯與單元測試，但尚未在模擬器上操作過。建議依下列順序測試，每項後面是預期結果。

> 前置：`MainActivity` 的 mock data 會在沒有球隊時建立「Test Team」（6 人）。

## 1. 登入與設定
- [ ] 已登入狀態啟動 → 直接到 Dashboard；Firebase 上既有的球隊／比賽會出現在球隊管理與歷史紀錄
- [ ] 設定 → 登出 → 回到登入畫面；再登入後資料由雲端重新下載
- [ ] 設定亮度後回到各頁面，亮度一致

## 2. 球隊管理
- [ ] 新增球隊：名稱空白時確認鍵不可按；重複名稱顯示錯誤；點卡片空白處不會關閉
- [ ] 展開球隊箭頭有旋轉動畫，人數正確
- [ ] 進入球員名單 → 新增球員：背號輸入「03」變「3」、重複背號顯示「此背號已被使用」
- [ ] 刪除球員／球隊：對話框帶名稱；刪除球隊後其球員一併消失
- [ ] 旋轉／切到背景再回來（或開發者選項「不保留活動」），球員名單與新增球員頁仍正常

## 3. 開始比賽
- [ ] 沒有 6 人以上球隊 → 「請先建立球隊」對話框
- [ ] 未填對手名稱時往後滑 → 彈回並顯示「輸入未完成」
- [ ] 數值超過上下限顯示 Toast（節數 1–4、犯規 1–9、暫停 1–9、每節 1–40 分鐘）
- [ ] 返回鍵 → 退出確認

## 4. 比賽中
- [ ] 各數據按鈕記錄後比分正確；PF 會先問進攻／防守犯規
- [ ] 防守犯規增加團隊犯規，進攻犯規不增加（但增加失誤）
- [ ] 下一節後團隊犯規歸零；第一節按補登顯示「第一節不須補登」
- [ ] 換人後名單正確；雙指／三指滑動依設定觸發對應數據
- [ ] 復原紀錄：編輯、刪除後比分正確
- [ ] 數據統計表顯示每位球員的實際數據（不再是全 0）
- [ ] 返回 → 儲存：回 Dashboard，再按開始比賽 → 詢問續賽 → 續賽後比分、節數、場上名單、犯規上限都與離開前相同
- [ ] 續賽詢問 →「儲存並開新局」：該場出現在歷史紀錄
- [ ] 續賽詢問 →「放棄」：該場不會出現在任何地方
- [ ] 比賽中按儲存圖示結束比賽：回 Dashboard，歷史紀錄出現該場，球隊的歷史場數 +1

## 5. 歷史紀錄
- [ ] 列表依日期新到舊，標題空白顯示「友誼賽」
- [ ] 點進比賽：勝／敗、比分、命中率圓環、得分組成長條圖、各節統計表數字合理
- [ ] 球員數據頁：點左上角可切換總和／各節；可左右捲動，且無法滑回球隊數據頁（legacy 行為），需點分頁
- [ ] 更多 → 分享：顯示上傳中，完成後網址已複製到剪貼簿
- [ ] 更多 → 刪除：該場消失，球隊歷史場數 -1

## 6. Firebase（需登入且有網路）
- [ ] 結束比賽、刪除歷史、新增／刪除球隊與球員後，Firebase Console 的 `users/{uid}` 節點同步更新
- [ ] 解除安裝重裝或換裝置登入，資料能完整下載
